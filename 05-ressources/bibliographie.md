## ℹ️ Note

La bibliographie reprend les ressources mentionnées dans le syllabus officiel BDOE633. Les ouvrages portent sur Oracle 19c et 12c ; le module utilise Oracle 23ai. Les principes d'administration, de sauvegarde et de supervision restent largement transposables ; les écarts de version sont signalés en séance lorsque nécessaire.
